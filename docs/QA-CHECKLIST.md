# Manual QA checklist

## Catalogue

- Product archive loads without PHP warnings.
- Search and category filters return the expected cards.
- Product pages show price, availability, ingredients and allergens.
- Empty filter results provide a clear recovery path.

## Locations and ordering

- Location cards and map markers open the correct details.
- Pre-order quantities reject invalid values.
- Required customer fields are validated.
- Public demo forms do not transmit real customer data.

## Responsive and accessibility

- Navigation works with keyboard and touch input.
- Focus states remain visible.
- Headings follow a logical hierarchy.
- Images contain useful alternative text.
- Layout is checked at 360 px, 768 px and desktop widths.

## Administration

- Product and location content can be created and edited.
- Settings persist after saving.
- Restricted actions require the expected user capability.
